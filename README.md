# Портфолио разработчика

Статический сайт на Astro, TypeScript и SCSS Modules. Без React, Tailwind и внешних UI-библиотек.

## Запуск

Требуется Node.js 22.12+ (или актуальная LTS).

```sh
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://127.0.0.1:4321).

```sh
npm run build
npm run preview
```

Сборка сначала проверяет типы и Astro-компоненты. Готовый статический сайт находится в `dist/`.

## Контент

Все данные находятся в **src/data/portfolio.ts**:

Русские данные — `portfolio`; английские тексты — `englishPortfolio` и `englishProjects`; интерфейс — `interfaceCopy`. Контакты, технологии и адреса проектов общие для обеих версий, поэтому изменения не нужно дублировать. Шаблон страницы — `src/layouts/PortfolioPage.astro`.

- `name`, `specialization`, `positioning`, `about` — личные данные и тексты;
- `directions` — направления работы;
- `stack` — группы технологий, заполняйте массивы `technologies`;
- `projects` — описание, роль, результат, технологии и ссылки. `visual` выбирает графическую CSS-обложку (`sentx`, `mybox`, `iec`, `sobol`, `metdent`, `flet`); `coverLabel` и `coverCaption` задают её надписи. Это авторские графические обложки, а не скриншоты сайтов;
- `contacts` — подпись, отображаемый контакт и `href` (`https://t.me/…`, `https://github.com/…`, `mailto:…`);
- `seo` — заголовок, описание и `siteUrl` с окончательным адресом сайта.

Квадратные скобки обозначают данные, которые необходимо заменить. Ссылки со значением `null` выводятся обычным текстом. Ненужные группы стека и проекты можно удалить из массивов. Пояснения о заполнителях исчезнут автоматически после замены названий проектов.

Дизайн-токены и сброс — `src/styles/global.scss`. Стили страницы — `src/styles/Home.module.scss`, стили проектов — `src/components/ProjectCard.module.scss`. Внешние шрифты и изображения не загружаются; используются системные шрифты и SVG/CSS-графика. Если нужны свои шрифты, используйте локальные WOFF2 с кириллицей.

## Публикация

Разместите содержимое `dist/` на любом статическом хостинге. Перед публикацией заполните `seo.siteUrl` для canonical и абсолютного Open Graph URL. Готовая OG-обложка — `public/og.png` (1200×630), её редактируемый исходник — `public/og.svg`.

## Доступность и анимации

Подтверждения стека каждого проекта, источники и ограничения публичной проверки описаны в `docs/project-technologies.md`.

Навигация работает без JavaScript. Весь контент доступен без JS; Intersection Observer добавляет появление при прокрутке только при поддержке API. Учитывается `prefers-reduced-motion`, включая изменение настройки во время просмотра. Есть ссылка пропуска навигации и заметный клавиатурный фокус.

## Графика Hero

`src/components/HeroGraphic.astro` и `HeroGraphic.module.scss` содержат анимированную графику: орбиты, сборку символа и лёгкий параллакс на устройствах с мышью. Анимация приостанавливается вне экрана и в скрытой вкладке; при `prefers-reduced-motion` отображается статичная композиция. React и сторонние библиотеки анимаций не требуются. Sass используется только при сборке.

## Языки и автоматический выбор

- `/ru/` — русская версия, `/en/` — английская. Прямые ссылки не перенаправляются, обе версии полностью доступны без JavaScript.
- `/` — точка автоматического входа. Сначала учитывается явный выбор RU/EN из `localStorage`, затем страна из кэша текущей сессии. Если страны ещё нет, выполняется запрос к `https://api.country.is/` без cookies и referrer; ответ ограничен таймаутом 1,2 секунды. Сайт использует только код страны и не сохраняет IP из ответа. Внешний сервис получает IP посетителя для определения страны.
- Для RU, BY, KZ, KG, TJ, UZ, AM, AZ, MD, TM выбирается русский язык; для остальных стран — английский. Это редактируемая политика аудитории в `src/lib/locale.ts`, а не определение юридического статуса стран.
- Если запрос недоступен, используется регион основного языка браузера; для языков без региона — языковой код. Это резервный вариант, он не гарантирует совпадение с физической страной. VPN влияет на определение страны по IP.
- Кнопки RU/EN всегда позволяют выбрать язык вручную, сохраняют якорь текущего раздела и имеют приоритет над геолокацией. Если хранилище браузера запрещено, переключатель всё равно работает обычными ссылками.
- На входной странице до определения страны отображается английский контент; без JavaScript он остаётся доступен вместе со ссылками RU/EN. На прямых языковых маршрутах геозапросов нет.
- В каждой версии есть свой `lang`, Open Graph, title, description и `hreflang`. Для абсолютных canonical/hreflang заполните `portfolio.seo.siteUrl`. Английская OG-обложка — `public/og-en.png`.

Проверка политики выбора языка: `npm test`.
